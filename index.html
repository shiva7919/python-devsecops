// course-overview

What this course covers

python-training-docs teaches core Python — variables, control flow, functions, and object-oriented programming — using the exact kinds of problems you'll be handed in your first month on an infrastructure or security team: parsing logs, validating configs, checking service health, and automating repetitive operational work.

module 01

Python Basics

Variables, conditions, and loops — applied to servers, IP addresses, config files, and Kubernetes objects.

module 02

Functions

Package repeatable operational tasks — disk checks, service restarts, deployments — into reusable functions.

module 03

Object-Oriented Programming

Model servers, containers, pipelines, and alerts as classes — the pattern behind most automation frameworks.

module 04

Generators

Stream huge log files and event feeds without blowing up memory, using yield and lazy evaluation.

practice

Hands-on Labs

Eight guided labs covering Linux automation, Docker, Kubernetes, log parsing, and security analysis.

practice

Mini Projects

Ten build-from-scratch projects, from a system info collector to a file integrity checker.
