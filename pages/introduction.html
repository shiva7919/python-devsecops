Introduction

Welcome. This course teaches Python from first principles, but every example is drawn from the work you'll actually do as an infrastructure, security, or platform engineering intern: checking whether a disk is nearly full, looping over a fleet of servers, parsing a firewall log, or modeling a Kubernetes cluster as an object.

How to use this documentation

Each module follows the same structure: theory, syntax, worked examples, a set of DevOps/security/cloud examples, exercises, a short quiz, and a summary. Work through modules in order — later modules assume you're comfortable with earlier ones.

Tip

Use the sidebar's checkmarks to track what you've completed, and press / anywhere to jump to search.

Prerequisites

  • No prior programming experience required.
  • Basic comfort navigating a Linux terminal is helpful (not required for the core modules, required for the labs).
  • A willingness to type out every example yourself rather than just reading it.

Setting up your environment

Install Python 3.10 or later. Verify the install from a terminal:

terminal
$ python3 --version
Python 3.11.6

$ python3 -m venv venv
$ source venv/bin/activate
(venv) $ python3 -c "print('environment ready')"
environment ready
Note

All examples in this course are written against Python 3.10+. Some syntax (like structural pattern matching) will not work on older interpreters.

The mindset: automation over repetition

Every module in this course exists to answer one question: how do I stop doing this by hand? If you find yourself SSHing into ten servers to check the same thing, or re-reading the same log file every morning, that's a signal a script belongs there instead. Keep that question in mind as you work through the material.
