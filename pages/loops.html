Loops

Loops are how a script scales from "check one server" to "check every server." Anywhere you'd otherwise copy-paste the same operation ten times, a loop belongs instead.

Theory

Python has two loop constructs: for, which iterates over a known collection (a list, a file, a range of numbers), and while, which repeats as long as a condition stays true. Infrastructure scripts lean heavily on for loops because most of what you're processing — server lists, log lines, API results — is already a collection.

Syntax

loops_syntax.py
servers = ["web-01", "web-02", "web-03"]

for server in servers:
    print(f"checking {server}...")

# while loop: repeat until a condition changes
attempts = 0
while attempts < 3:
    print(f"attempt {attempts + 1}")
    attempts += 1

break, continue, and enumerate

loop_controls.py
ports = [22, 80, 443, 3389]

for i, port in enumerate(ports):
    if port == 3389:
        print(f"risky port found at index {i}, stopping scan")
        break
    if port == 22:
        continue  # skip SSH, already reviewed
    print(f"reviewing port {port}")

Practical examples

Processing log files line by line

parse_log.py
with open("/var/log/app/error.log") as f:
    for line in f:
        if "ERROR" in line:
            print(line.strip())

Reading an inventory file

inventory_loop.py
inventory = [
    {"host": "db-01", "role": "database"},
    {"host": "web-01", "role": "frontend"},
]

for node in inventory:
    print(f"{node['host']} -> {node['role']}")

Monitoring Kubernetes pods

pod_status.py
pods = {"api-7d9f": "Running", "api-3a1c": "CrashLoopBackOff", "worker-2b": "Running"}

for pod_name, status in pods.items():
    if status != "Running":
        print(f"unhealthy pod: {pod_name} ({status})")

Looping over AWS EC2 instances

ec2_loop.py
instances = [
    {"id": "i-0a1b2c", "state": "running", "type": "t3.medium"},
    {"id": "i-0d4e5f", "state": "stopped", "type": "t3.large"},
]

running_count = 0
for instance in instances:
    if instance["state"] == "running":
        running_count += 1

print(f"{running_count} of {len(instances)} instances running")
Warning

A while loop with no guaranteed exit condition will hang your script (or your CI job) indefinitely — always ensure the loop variable moves toward the exit condition.

Exercises

  1. Given a list of five hostnames, print each one prefixed with its position (1: web-01, etc.) using enumerate.
  2. Loop through a dictionary of {service_name: is_running} and print only the services that are down.
  3. Write a while loop that simulates retrying a failed deployment up to 4 times, printing each attempt number.

Knowledge check

Summary

  • for loops iterate over collections — the default choice for server lists, log lines, and API results.
  • while loops repeat based on a condition — useful for retries and polling.
  • break, continue, and enumerate() give you fine control over iteration.
