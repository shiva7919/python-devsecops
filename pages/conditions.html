Conditions

Conditions let a script make decisions: restart a service only if it's down, block a login only after too many failed attempts, flag a firewall rule only if it's too permissive. Almost every automation script is, underneath, a chain of conditions.

Theory

An if statement evaluates an expression for truthiness and runs its block only when that expression is True. Python's elif/else chain lets you branch across multiple mutually-exclusive cases without nesting.

Syntax

conditions_syntax.py
disk_used_percent = 92

if disk_used_percent >= 90:
    print("CRITICAL: disk almost full")
elif disk_used_percent >= 75:
    print("WARNING: disk usage high")
else:
    print("OK: disk usage normal")

Practical examples

Service health check

service_health.py
service_status = "stopped"
restart_attempts = 2
max_restart_attempts = 3

if service_status == "stopped" and restart_attempts < max_restart_attempts:
    print("Attempting restart...")
elif service_status == "stopped":
    print("ALERT: max restart attempts reached, paging on-call")
else:
    print("Service is healthy")

Login validation

login_validation.py
failed_attempts = 5
account_locked = False

if failed_attempts >= 5 and not account_locked:
    account_locked = True
    print("Account locked after 5 failed attempts")

Password policy check

password_policy.py
password = "Prod$erver2026"

has_length = len(password) >= 12
has_digit = any(c.isdigit() for c in password)
has_symbol = any(c in "!@#$%^&*" for c in password)

if has_length and has_digit and has_symbol:
    print("Password meets policy")
else:
    print("Password rejected: does not meet policy")

Firewall rule validation

firewall_check.py
source_cidr = "0.0.0.0/0"
port = 22

if port == 22 and source_cidr == "0.0.0.0/0":
    print("HIGH RISK: SSH open to the entire internet")
Tip

Prefer clear boolean names (is_healthy, has_valid_cert) over cryptic flags — your future self debugging a 3am page will thank you.

Exercises

  1. Write a check that prints "scale up" if CPU load is above 80%, "scale down" if below 20%, and "steady" otherwise.
  2. Given a list of open ports, print a warning for any port that is 21, 23, or 3389 (commonly restricted protocols).
  3. Write a condition that flags a TLS certificate as "expiring soon" if fewer than 14 days remain, using an integer variable days_until_expiry.

Knowledge check

Summary

  • if / elif / else branch execution based on boolean expressions.
  • Combine conditions with and, or, and not to express real operational rules.
  • Most health checks, validation logic, and security gates in automation scripts are conditions at their core.
