Objective: automate a routine Linux health check

Prerequisites: Modules 01–04 (Variables through Functions); access to a Linux shell (or WSL).

  1. Write a function get_uptime() that runs uptime via subprocess.run and returns the decoded output.
  2. Write get_disk_usage(path="/") using shutil.disk_usage(), returning used/total/percent.
  3. Combine both into a health_check() function that prints a one-line summary.
  4. Run the script and confirm it prints real values from your machine.
linux_health_check.py
import subprocess, shutil

def get_disk_usage(path="/"):
    total, used, free = shutil.disk_usage(path)
    percent = round((used / total) * 100, 1)
    return percent

def health_check():
    usage = get_disk_usage()
    print(f"disk usage: {usage}%")

health_check()

Expected output: disk usage: 47.2% (value depends on your machine).

Challenge: extend health_check() to also print available memory using the psutil package, and raise a warning if disk usage exceeds 90%.

Objective: extract and count error types from a raw log file

Prerequisites: Modules 03–04 (Loops, Functions).

  1. Create a sample log file with a mix of INFO, WARNING, and ERROR lines.
  2. Write parse_log(path) that loops through the file and counts occurrences of each log level.
  3. Print a summary table of counts.
  4. Print only the ERROR lines, with their line numbers.
log_parser.py
def parse_log(path):
    counts = {"INFO": 0, "WARNING": 0, "ERROR": 0}
    with open(path) as f:
        for line in f:
            for level in counts:
                if level in line:
                    counts[level] += 1
    return counts

Expected output: {'INFO': 14, 'WARNING': 3, 'ERROR': 2}

Challenge: extend the parser to extract timestamps and report the time range covered by the log file.

Objective: build a repeatable service health poller

Prerequisites: Modules 02–05 (Conditions through OOP).

  1. Model a Service class with name, status, and a check() method.
  2. Simulate three services with different statuses.
  3. Loop through them and print an alert for anything not "running".
  4. Track how many consecutive checks a service has failed.
service_monitor.py
class Service:
    def __init__(self, name, status="running"):
        self.name = name
        self.status = status
        self.failed_checks = 0

    def check(self):
        if self.status != "running":
            self.failed_checks += 1
        return self.status

Expected output: ALERT: payments-api is stopped (2 consecutive failed checks)

Challenge: add auto-restart logic that flips status back to "running" after 3 failed checks, simulating a self-healing service.

Objective: script container status checks

Prerequisites: Modules 04–06 (Functions, OOP, Constructors); Docker installed.

  1. Write list_containers() using subprocess.run(["docker", "ps", "--format", "{{.Names}}:{{.Status}}"]).
  2. Parse the output into a list of (name, status) tuples.
  3. Print containers that are not "Up".
  4. Wrap the result in a small ContainerReport class with a summary() method.
docker_status.py
import subprocess

def list_containers():
    result = subprocess.run(
        ["docker", "ps", "--format", "{{.Names}}:{{.Status}}"],
        capture_output=True, text=True
    )
    return [line.split(":", 1) for line in result.stdout.strip().splitlines() if line]

Expected output: a list like [['web', 'Up 2 hours'], ['redis', 'Up 2 hours']]

Challenge: flag any container whose uptime is under 5 minutes as "recently restarted" — a possible crash-loop signal.

Objective: summarize pod health across a namespace

Prerequisites: Modules 05–07 (OOP through Generators); familiarity with kubectl output format.

  1. Given a sample list of pod dicts (simulating kubectl get pods -o json output), write a generator unhealthy_pods(pods).
  2. Yield only pods where status != "Running".
  3. Build a NamespaceReport class that consumes the generator and counts issues by pod.
  4. Print a final summary line.
k8s_pod_report.py
def unhealthy_pods(pods):
    for pod in pods:
        if pod["status"] != "Running":
            yield pod

Expected output: 2 unhealthy pods found in namespace 'payments-prod'

Challenge: group unhealthy pods by status value (CrashLoopBackOff, Pending, etc.) and print counts per group.

Objective: validate a YAML config before deployment

Prerequisites: Module 04 (Functions); the PyYAML package.

  1. Create a sample config.yaml with a few required keys (service_name, replicas, image).
  2. Write validate_config(path, required_keys) that loads the YAML and checks every required key is present.
  3. Return a list of any missing keys.
  4. Print a pass/fail result based on that list.
validate_config.py
import yaml

def validate_config(path, required_keys):
    with open(path) as f:
        config = yaml.safe_load(f)
    return [key for key in required_keys if key not in config]

Expected output: missing keys: ['replicas'] (or [] if the config is valid).

Challenge: add type validation — confirm replicas is an int and image matches a name:tag pattern.

Objective: detect brute-force login attempts from an auth log

Prerequisites: Modules 02–04, 07 (Conditions, Loops, Functions, Generators).

  1. Create a sample auth log with repeated "Failed password" lines from the same IP.
  2. Write a generator failed_logins(path) yielding (ip, timestamp) tuples.
  3. Count failures per IP using a dictionary.
  4. Flag any IP with 5+ failures as a brute-force suspect.
bruteforce_detector.py
def count_failures_by_ip(failures):
    counts = {}
    for ip, _ in failures:
        counts[ip] = counts.get(ip, 0) + 1
    return {ip: n for ip, n in counts.items() if n >= 5}

Expected output: {'203.0.113.44': 8}

Challenge: add a time-window check — only count failures that occurred within a 10-minute span as a single brute-force burst.

Objective: build a scriptable backup routine with rotation

Prerequisites: Modules 04–06 (Functions, OOP, Constructors).

  1. Write create_backup(source_dir, dest_dir) using shutil.make_archive.
  2. Name each archive with a timestamp, e.g. backup_2026-08-06_0300.zip.
  3. Write rotate_backups(dest_dir, keep=5) that deletes the oldest archives beyond the retention count.
  4. Wire both functions together into a single run_backup_job().
backup_job.py
import shutil, os, datetime

def create_backup(source_dir, dest_dir):
    stamp = datetime.datetime.now().strftime("%Y-%m-%d_%H%M")
    archive_name = os.path.join(dest_dir, f"backup_{stamp}")
    return shutil.make_archive(archive_name, "zip", source_dir)

Expected output: backup_2026-08-06_0300.zip created

Challenge: add basic integrity verification — after creating the archive, re-open it and confirm the expected number of files are present.
