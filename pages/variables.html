Variables

A variable is a name bound to a value in memory. In infrastructure code, variables are how you hold onto the things you're operating on: a hostname, an IP address, a threshold, a config value pulled from the environment.

Theory

Python is dynamically typed: you don't declare a variable's type up front, and a name can be rebound to a value of a different type later. The type lives with the value, not the name. This is convenient for scripting but means it's on you to keep track of what a variable actually holds — especially when that value came from a config file, an API response, or an environment variable, all of which typically arrive as strings.

Syntax

variables_syntax.py
# assignment: name = value
hostname = "web-prod-01"
port = 8080
is_healthy = True
cpu_load = 0.42

# multiple assignment
region, zone = "us-east-1", "us-east-1a"

# type check
print(type(port))   # <class 'int'>

Naming rules

  • Letters, digits, and underscores only — can't start with a digit.
  • Case-sensitive: server_ip and Server_IP are different names.
  • Convention: snake_case for variables, UPPER_SNAKE_CASE for constants.

Environment variables

Config values that change per environment (dev/staging/prod) are almost never hardcoded — they're read from the environment at runtime using the os module.

read_env_config.py
import os

# .get() with a default avoids a crash if the var isn't set
db_host = os.environ.get("DB_HOST", "localhost")
log_level = os.environ.get("LOG_LEVEL", "INFO")
api_key = os.environ.get("API_KEY")  # None if unset — check before use

if api_key is None:
    print("warning: API_KEY not set")
Warning

Environment variables are always strings. os.environ.get("MAX_RETRIES") returns "5", not 5 — cast explicitly with int() before doing arithmetic on it.

Exercises

  1. Create variables for a server's hostname, ip_address, and is_online status, then print all three in one formatted string.
  2. Read a DEPLOY_ENV environment variable with a default of "development", and print which environment the script believes it's running in.
  3. Given disk_used_gb = 87.5 and disk_total_gb = 100, compute and print the percentage used.

Knowledge check

Summary

  • Variables bind a name to a value; Python infers the type from the value.
  • Infra scripts lean heavily on str, int, float, and bool for hostnames, ports, metrics, and flags.
  • Environment variables arrive as strings — always cast before doing math on them.
